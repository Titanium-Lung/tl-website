Top Project

The project I have that I'm the most proud of is a website I made to host Archipelago Servers. It allows the user to upload a zip file of their generated multiworld, and it'll host an Archipelago Server on a random port. It has pages to show the progress of the multiworld, and the progress of individual players, as well as a Sphere tracker and a Stats page.

It is a Full Stack web app with a Python (Flask) backend and Javascript (React) frontend. It's backed by a PostgresSQL database.
