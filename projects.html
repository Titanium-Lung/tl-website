Archipelago Hosting Service

I created a custom full stack website to host Archipelago games for me and my friends to use.

Archipelago is an open source program made by many people. It randomises items between multiple video games, meaning that if you collect a location in your game, it will send a random item to a random game. The people who made Archipelago have their own website and servers, but I wanted to make my own, for more customisability, and also to use the servers of the Computer Science House.

The backend is written in Python, using Flask as a framework, and the frontend is written in Javascript using React. The user uploads the zip file generated by the Archipelago multiworld generator, and it saves the files to a folder in the backend. It starts up an Archipelago server (using the archipelago source code), and reads relevant information into a PostgreSQL database. This information can be found in many places throughout the website, including a full multiworld tracker, individual trackers, and more.

One of the extra features I added is a Stats page. Since you have to log in to the site (using a Google or CSH account), the site is able to attach information to your account, including being able to assign yourself to games you are playing. The Stats page displays many statistics about different games and sessions the user has been a part of. The SQL queries for the stats page were tough to write. It's got nested queries, group by, order by, the works.

As I mentioned, it's deployed on the servers of Computer Science House. This is done using a service called OpenShift. I create a new deployment (one each for the backend and frontend) and point it to the Dockerfile, and it builds it. I then configure the routes and secrets (like environment variables), and also set up a webhook with Git.

This particular project required some finagling because it hosts Archipelago servers on various different ports. So I had to create multiple Services to direct traffic to the correct ports.

It can be found at archipelago.csh.rit.edu

Github link: Archipelago CSH

Silksong Build Generator

This is another website I made, this time a React (Typescript) frontend, and a Golang backend (using the Gin framework).

The backend contains JSON files containing all the tools and crests in Silksong. When the program starts it reads those files into structs. The frontend has a couple of customisation options for your Silksong build, then pressing Generate sends a request to the backend, and it sends back a random crest+tool build with the user's specifications.

It can be viewed at silksong-build-generator.cs.house

Github link: Silksong Build Generator

Basketpong

Basketpong is a mashup between Basketball and Pong. Ever played one of those 2D basketball games where the little characters have to throw the ball into the hoop? This game is like that, except the entire opposite wall is your basket, and each player has a Pong paddle to block the other player from hitting their wall.

Players can't move past their half of the court, and it's first to 5 points.

I made it using Godot, using GDScript, which is a language specific to Godot. It's like Python. I had a hard time with the Physics, since the ball would keep bouncing the wrong direction. I found and installed a physics engine, and that mostly fixed the problem. I made the assets myself, and all the UI myself as well.

I don't currently have a way for other people to play it. I'll work on that.

Github link: Basketpong
